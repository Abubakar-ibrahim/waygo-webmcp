# WAYGO Demo Script — 2 minutes 30 seconds

## 0:00–0:20 — Problem

“African travel packages are often fragmented across WhatsApp, social media and agency websites. Travellers must manually compare prices and inclusions while also deciding which agencies to trust.”

Show the WAYGO marketplace and its verified package cards.

## 0:20–0:40 — Why WebMCP

“A conventional agent has to interpret the interface and guess which controls to manipulate. WAYGO exposes precise, structured tools, so the agent can work directly with the marketplace while I remain in the interface.”

Show the WebMCP tools discovered by the browser agent.

## 0:40–1:25 — Agent workflow

Use this prompt:

> I want to perform Umrah from Abuja in October with a budget of ₦2.5 million. Find suitable packages, verify the best agency, compare the strongest two options and shortlist both.

Show the budget changing, results narrowing to two Abuja options, Safar Trails verification evidence, both packages selected for comparison and the shortlist count changing to two.

## 1:25–2:05 — Human control

Say:

> Prepare contact with the best agency, but do not book or pay.

Show the approval dialog and explain:

“The agent has done the repetitive work, but it cannot cross the consequential boundary. I decide whether to approve contact.”

## 2:05–2:30 — Closing

“WAYGO demonstrates what agent-native commerce can look like for Africa: structured tools for reliable delegation, a shared visual workspace for transparency and human approval where it matters.”

End on the WAYGO logo and live URL.
